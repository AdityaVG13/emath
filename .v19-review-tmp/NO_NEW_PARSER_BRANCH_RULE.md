# No New Domain Parser Branch Rule

A new domain concept must first attempt:

```text
generic declaration kind
generic section
registered symbol/binder
syntax-pack expansion
Feature Capsule lowering
```

A Stage-0 grammar addition is allowed only when:

1. the form cannot be represented through existing generic forms;
2. at least three materially different domains need it;
3. ambiguity/confusable/precedence analysis passes;
4. the core-cost and migration impact are measured;
5. an ELP explicitly rejects data-driven alternatives.

Domain names never justify a core branch.
