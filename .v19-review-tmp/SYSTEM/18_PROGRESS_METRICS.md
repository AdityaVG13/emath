# System Progress Metrics

Measure progress by:

```text
percentage of current features assigned FeatureIDs
percentage with unique authority
percentage with complete capsules
percentage with positive/negative/mutation conformance
percentage with reference/provider disposition
percentage with full projection closure
percentage migrated from manual to generated views
V16 catalog promotion distribution
blocking Spec Holes
agent orientation cost
rework and stale-view rate
cross-implementation conformance
```

Raw feature count is not a quality metric.
