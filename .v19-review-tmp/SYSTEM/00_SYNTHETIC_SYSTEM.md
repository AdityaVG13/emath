# Synthetic System

The repository is one linked system, not an assemblage.

```text
LAW PLANE
    project constitution and authority firewall

MEANING PLANE
    Feature Capsules and Meaning Spine

REALIZATION PLANE
    parser, sema, worlds, providers, execution, codegen

EVIDENCE PLANE
    conformance, mutation, differential, artifact checks

EVOLUTION PLANE
    ELPs, editions, migrations, Spec Holes

AGENT PLANE
    Agent Start, Task/Context Capsules, Impact Closure, receipts

DISTRIBUTION PLANE
    Language Image, field packs, locks, generated reference
```

FeatureID is the join key across all planes.
