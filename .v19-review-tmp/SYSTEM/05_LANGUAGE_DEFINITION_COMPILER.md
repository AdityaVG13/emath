# Language Definition Compiler

Inputs:

```text
Stage-0 seed
accepted capsules
authority lock
edition policy
migration graph
Spec Holes
conformance manifests
```

Outputs:

```text
Language Image
parser/operator/schema tables
typed feature handles
lowering/reference programs
world and provider manifests
diagnostics/routes
docs/LSP/capability views
migration graph
agent index
gap radar
```

Stable generation fails on duplicate identity, unresolved dependency, alias collision, missing
projection, blocking hole, invalid migration, or failed conformance.
