# Feature Capsule

## Envelope

```text
identity
class
maturity
edition
summary
dependencies
surface
canonical lowering
semantics
exactness
effects
worlds
reference
artifact
projections
diagnostics
conformance
evolution
agent metadata
```

## Purpose

One capsule prevents separate implementers from deciding independently:

```text
what parses
what it means
where it lowers
what exactness is promised
which worlds apply
what may execute it
what output is valid
which diagnostics are canonical
what tests complete it
how it evolves
```
