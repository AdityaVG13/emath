# Agent-Native Synthesis

The durable system is not the agent. The agent is a temporary reasoning process attached to a
persistent semantic substrate.

## Center of gravity

```text
not files
not crates
not prose
not chat history
not the current model

FeatureID + meaning + evidence + dependency position
```

Every useful view is compiled from that center.

## Five synthetic laws

### 1. Context is compiled, not collected

The agent receives the smallest authority-complete graph cut. It does not accumulate arbitrary
search results until it feels informed.

### 2. A task is a semantic transaction

A Task Capsule declares the intended delta, preserved invariants, impact closure, acceptance,
resource budget, and rollback before edits begin.

### 3. Unknowns are state

An unresolved question is a Spec Hole with ownership and alternatives. It is never hidden inside
an implementation choice.

### 4. Failure accretes

A failed hypothesis, mutation, provider path, or migration becomes reusable negative knowledge and
changes future orientation/search.

### 5. Views are disposable; identities are durable

Context summaries, docs, indexes, and generated code may be regenerated. Feature identity,
decisions, conformance evidence, and receipts persist.

## Result

A newer agent can understand more with less reading because prior work has increased the quality of
the semantic index rather than merely increased repository size.
