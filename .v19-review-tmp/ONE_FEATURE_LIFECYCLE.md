# One Feature Lifecycle

```text
cataloged
→ Spec Hole resolution
→ proposed capsule
→ accepted semantics
→ conformance authored
→ reference/provider realized
→ projections generated
→ dual-run
→ authority switched
→ stable
→ compatible additions or explicit migration
→ deprecated
→ retired
```

A feature may remain valuable at `cataloged`, `proposed`, or `diagnostic`; status must be honest.
