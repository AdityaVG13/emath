# Source Basis

This package preserves the project's established principles:

```text
uniform declaration and binder syntax
exact-first mathematics
no silent float degradation
typed mathematical diagnoses and routes
capability cells rather than domain opcodes
deterministic self-describing artifacts
readable `.emath` programs
router-not-gate output discipline
worlds with explicit representations, capabilities, strategy, and evidence
syntax-pack growth over a small core
compiling is not proving
```

V19 changes how these principles become executable and agent-safe; it does not discard them.
