# Agent-Accretive Invariants

After a successful task, at least one durable system object improves:

```text
Feature Capsule becomes more complete
Conformance Corpus becomes more discriminating
diagnostic route becomes more precise
migration becomes safer
provider/world coverage becomes known
Spec Hole becomes narrower or resolved
negative knowledge prevents repeated work
agent context becomes smaller or more accurate
```

A task that only adds code while leaving semantic and agent state unchanged is incomplete.
