# Agent Memory Model

Durable memory classes:

```text
semantic:
    capsules, identities, dependencies

decisional:
    Spec Holes and decisions

evidential:
    conformance, mutations, provider checks

operational:
    Task Capsules, receipts, measurements

negative:
    failed attempts, regressions, invalid assumptions

historical:
    superseded specifications and migrations
```

No durable state depends on a hidden chain of thought. Reasoning is preserved as decisions,
assumptions, evidence, counterexamples, and reproducible steps.
