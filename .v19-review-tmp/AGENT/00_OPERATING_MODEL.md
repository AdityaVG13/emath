# Agent Operating Model

1. Read `AGENT_START.json`.
2. verify commit, ImageID, and authority lock;
3. resolve a Task Capsule;
4. generate Impact and Context Capsules;
5. read prescribed sources in order;
6. convert unresolved choices into Spec Holes;
7. edit only allowed categories;
8. run focused then closure gates;
9. emit Change Receipt;
10. regenerate language and agent indexes.
