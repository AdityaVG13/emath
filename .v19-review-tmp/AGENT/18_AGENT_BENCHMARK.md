# Agent Ergonomics Benchmark

Cold-start tasks:

```text
locate authority for one feature
find direct owner and tests
predict impact of a semantic change
identify exactness/world hazards
resume interrupted migration
distinguish generated from normative files
```

Measure correctness, orientation tokens, files read, tool calls, time to first useful gate, rework,
and receipt completeness. Compare V19 context against unrestricted repository browsing.
