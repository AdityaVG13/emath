# Context Gradient

```text
L0 <= 600 tokens:
    baseline, task, invariants, exact next command

L1 <= 2,500 tokens:
    feature, dependencies, owner, gates, hazards

L2 <= 8,000 tokens:
    relevant contracts, goldens, diagnostics, migrations

L3:
    exact source slices required for implementation

L4:
    history, rejected alternatives, and wave research only when needed
```
