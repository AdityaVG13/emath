# Transition Strategy

## Epoch 0 — Freeze and inventory

Pin commit; assign provisional FeatureIDs; record reference, grammar, code, test, world, artifact,
and diagnostic anchors.

## Epoch 1 — Authority lock and tooling

No behavior change.

## Epoch 2 — Leaf features

```text
Int
addition
exact equality
sum
function
free-symbolic world
```

## Epoch 3 — Cross-wave slices

```text
V15 cipher and puzzle
one V16 promotion
V17 campaign
V18 criterion
```

## Epoch 4 — Generated views

Generate capability/reference/LSP/agent projections.

## Epoch 5 — Core contraction

Move eligible domain productions to syntax packs with editions and goldens.

## Epoch 6 — Fixed point

Stage 1 and Stage 2 agree.

Every feature stays rollback-capable until legacy authority retires.
