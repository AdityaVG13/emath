# emath Host Integration Examples

Reference projects demonstrating how external Rust applications consume, embed, and extend artifacts generated by the emath compiler pipeline.

## Overview

| Example | Purpose | Dependencies |
|---|---|---|
| [`hotpath-experiment/`](hotpath-experiment/) | Measured baseline/candidate experiment decided by an authored evaluator (`emath experiment`) | Standalone Cargo crates |

## Architecture Notes

- **Inspectable Code Generation**: Mathematical models compile down to standard, readable Rust crates published under `target/emath/` or standalone workspaces.
- **Zero-Runtime Overhead**: Once compiled into a Rust crate, consumer applications link mathematical kernels with native performance and no interpretation overhead.
