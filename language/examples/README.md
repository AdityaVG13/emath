# Language Examples

Cross-domain example programs illustrating emath semantics. The intended
reading order matches the table below; examples are listed alphabetically by
filename but should be studied in this order.

| # | Example | Focus |
|---|---------|-------|
| 1 | [hello-square.emath](hello-square.emath) | Minimal model entry point |
| 2 | [stateful-affine-scorer.emath](stateful-affine-scorer.emath) | Stateful scoring model |
| 3 | [arbitrary-glyphs.emath](arbitrary-glyphs.emath) | Glyph label flexibility |
| 4 | [cache-policy.emath](cache-policy.emath) | Compile-time caching policy |
| 5 | [tensor-program.emath](tensor-program.emath) | Tensor-centric program |
| 6 | [graph-router.emath](graph-router.emath) | Graph structure routing |
| 7 | [heat-pde.emath](heat-pde.emath) | PDE-style dynamics |
| 8 | [conjecture-search.emath](conjecture-search.emath) | Conjecture-driven search |
| 9 | [custom-provider.emath](custom-provider.emath) | Provider integration |
| 10 | [custom-kind.emath](custom-kind.emath) | Custom kinds and schema |
| 11 | [token-compression-system.emath](token-compression-system.emath) | Token compression workflow |
| 12 | [dynamic-mass-spring.emath](dynamic-mass-spring.emath) | Phase 3 acceptance demo (mass-spring) |
| 13 | [host-cache-policy.emath](host-cache-policy.emath) | Host-side caching |
| 14 | [parametric-unknown-operator.emath](parametric-unknown-operator.emath) | Unknown operator parameterization |
| 15 | [certificate-checked-optimization.emath](certificate-checked-optimization.emath) | Certificate-verified optimization |

Examples illustrate intended semantics; the phase documents state when each
becomes executable.
