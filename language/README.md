# emath Language Assets

- `grammar/emath.ebnf` is the V5 design grammar.
- `spec/` is the normative semantic specification.
- `templates/` contains blank declaration/project/provider/kind scaffolds.
- `examples/` contains cross-domain examples; files `00_*` and `09_*` onward are V5 additions, while `01_*` through `08_*` preserve the V4 example corpus.
- `stdlib/` describes the initial standard library and provider contracts.

Examples illustrate intended semantics; the phase documents state when each becomes executable.
