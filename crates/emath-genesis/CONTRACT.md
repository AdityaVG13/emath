# emath-genesis

## Purpose and layer

- Tier 6, semantic genesis substrate (per CRATE_MAP).
- Minimal Semantic Genesis evaluator and built-in example worlds.
- Hosts the G1 world-side stage, moved from emath-syntax (world-side fence): the forest module builds a bounded parse forest over a genesis body expression, infers the world signature, and constructs emath-term and emath-world-ir values directly.
- emath-syntax keeps the G0 emath custom section parser and re-exports this module for the CLI.

## Public types and semantics

- FirstOrderWorld trait: generic first-order world over a value type and an error type; constant resolves nullary symbols, apply applies an operator to evaluated arguments. World ABI (fjxh.7): carrier (`Value`), constants, variables (`Environment` + `evaluate`), apply, effects (`effects()`, default empty; seed worlds are pure), budgets (`evaluate_bounded` under `WorldBudget`; exhaustion is typed `EvalError::BudgetExhausted`, never a partial value), evidence (`evidence() -> WorldEvidence { world, origin, laws }`, required; every world names itself for result bundles), and `admits(&Signature)` (portfolio applicability; defaults `false`; a world claims a signature explicitly, never by omission). A NEW world implements the trait only; the evaluator gains no match arm for it.
- EvalError enum: MissingVariable, UnknownSymbol, Arity (symbol, expected, actual), BudgetExhausted { steps } (World ABI budget seam); implements std::error::Error.
- WorldBudget { max_steps }: node-visit metering for evaluate_bounded; evaluate delegates with u32::MAX (unchanged behavior).
- WorldEvidence { world, origin, laws }: stable per-world evidence record (consumed by result bundles; fjxh.8 no-naked-answers). OWNED (String/Vec) since fjxh.13: runtime-authored worlds cannot borrow `'static` names; static seed worlds keep the one-line shape via `WorldEvidence::seed(world, laws)`.
- WorldName enum (FreeSymbolic, BooleanAlien, ModularAlien) with stable as_str tokens; default_portfolio_order() (doctrine order: free symbolic, Boolean when applicable, modular when applicable); WorldDisposition { selected, trail }; `select_world(signature, exclude)` records EVERY candidate verdict (`applicable` / `not applicable` / `excluded`) and selects the first applicable world in order; `selected == None` is a typed disposition with the full trail; never a silent fallthrough, never an invented world. Worlds are passed explicitly to the evaluator; the strict lane never selects one.
- `evaluate_counted(term, world, environment, budget) -> Result<(Value, u32), Error>`: `evaluate_bounded` with the step count (producer seam for the envelope's `cost_steps`); `evaluate_bounded`/`evaluate` behavior unchanged.
- world_result module (schema `emath.world-result`, version 1, fjxh.8): the no-naked-answers ENVELOPE over the World ABI producer. `WorldResult` labels world, origin, method, term (canonical), inputs, assumptions (declared effects), disposition, evidence (laws), cost_steps; `validate` refuses naked results typed (`NakedResultRefusal`: `MissingWorld` = E-WORLD-001, `MissingMethod` = E-WORLD-002; a bare scalar never enters a bundle). `Disposition` is first-class: `Answer{canonical}` / `Open{missing}` (first missing valuation, deterministic fail-fast) / `Refused{reason}` (unknown symbol, budget exhaustion) / `Fault{detail}` (world contract violation). `ResultBundle::new` validates every result and stamps a deterministic content id (`fnv1a64:<hex>` over the length-framed canonical encoding); replay from bundle IDs reconstructs the labeled result (same producer + inputs + budget rebuild the same id). `to_json` is BTreeMap-ordered (genesis receipt convention; CLI and WASM consume the same bundle; no forked result type). `evaluate_labeled(term, world, environment, budget, label_value)` runs the producer and wraps ANY outcome (answers, open terms, refusals, faults) as a labeled result.
- FreeTermWorld: free symbolic world whose values remain Terms (structural, no hardcoded meaning); admits any signature.
- BooleanAlienWorld: Boolean interpretation of the reference alien signature (z true, join xor, neg not, times and).
- ModularAlienWorld: modular-17 interpretation (z = 3, join add, neg square, times multiply, rem_euclid(17)).
- world_decl module (fjxh.13): user-defined and law-synthesized worlds enter the World ABI as validated DATA; the evaluator gains no match arm for them. `WorldDecl { name, origin, laws, domain, constants, operations }` (finite carrier, constants, TOTAL `OperationTable`s) → `user_defined_world(decl)` validates (non-empty carrier within `MAX_WORLD_SIZE = 6`, constants and every table element in the carrier, `|domain|^arity` rows per table, arity ≥ 1 for operations) into an executable `UserDefinedWorld` (FirstOrderWorld over `String` values; `admits` claims only declared symbols with matching arities). `WorldOrigin::{UserDefined, Synthesized}` rides the evidence into every bundle; a synthesized world is never presented as claimed Real meaning. `synthesize_world(name, law, domain)` builds the deterministic canonical model of a `WorldLaw` (closed set: `Commutative` → `t(i,j)=d[min(i,j)]`, `Idempotent` → `t(i,j)=d[i]`, `IdentityElement{e}` → two-sided identity by construction; carrier-order, no search) over a toy-size carrier, law-labeled and independently checkable via `table(symbol).row(...)`. `ModelClaim { symbol, arguments, expected }` + `check_model` check claims against the world's OWN tables: a claim the world refutes is typed `WorldDeclError::FalseModel` (E-WORLD-007), never a silent agreement with a wrong model. `attach_world(source, source_id, decl)` enforces the strict vs Genesis/custom firewall at the attachment seam: `WorldSourceClass::Strict` refuses typed (`StrictFirewall`, E-WORLD-006; a strict Gaussian file never runs a modular world); `Custom` attaches. Other refusals typed: `EmptyDomain` (E-WORLD-003), `UnknownElement` (E-WORLD-004), `IncompleteTable` (E-WORLD-005), `SizeBoundExceeded` (E-WORLD-008 decl / E-SYNTH-001 synthesis), identity outside carrier (E-SYNTH-002).
- Environment<V> type alias: BTreeMap<VariableId, V> free-variable valuation.
- evaluate fn: total recursive evaluator over Term, propagating world errors via W::Error: From<EvalError>.
- free_symbolic_world and reference_alien_term fns: produce provider-neutral WorldIr and the reference term/signature. (not exhaustive; see the forest module.)
- vm module (schema emath.vm, version 1): explicit-stack semantic VM. VmBudget (step ceiling; seed_default 4096), VmStep/VmTrace (deterministic per-frame trace with canonical text encoding), run/resume (metered execution returning VmOutcome::Complete { value, steps, trace } or VmOutcome::Suspended(VmContinuation) when the budget is exhausted; continuations resume losslessly with a fresh budget).
- csa module (schema emath.csa, version 1): canonical seeded algebra, the totality baseline (ADR-003). OnePointWorld (degenerate one-point algebra, total). SeededCsaWorld (seeded FNV-1a mixing over u64: total, bit-exact reproducible per seed; distinct seeds are the built-in negative control). CSA_MEANING_CLAIM labels every CSA artifact as never author-intended meaning.
- specialization module (SG-17): SpecializationCache keyed by WorldId, with hit/miss/challenge counters. challenge(bound, presented) reuses a cached specialization only when WorldId is unchanged; an identity change is SpecializationChallenge::IdentityChanged (never a silent reuse). Process-local BTreeMap; no on-disk format.
- binder module (SG-10, schema emath.binder, version 1): scoped binders over the term IR. BinderTerm (Leaf term or nested Bind), ScopedBinder (kind, family, domain, bound variable, body). Four families with distinct meaning claims: Structural (defined as its finite expansion), OpaqueSeeded (seeded identity only, via opaque_identity(seed)), FiniteAnalogue (expands as a declared finite analogue, no continuum claim), Conventional (notation preserved, expansion refuses). Kinds: sum, product, integral, derivative, limit, custom(name). Capture-avoiding substitution alpha-renames with deterministic `name#N` fresh names; canonical form is alpha-invariant (de Bruijn `bound(i)` rendering) and excludes budgets; binder_id is FNV-1a64 over the versioned canonical form. expand(combine, budget) left-folds body instantiations with a single combining symbol (v1 limitation), metered by BinderBudget (default 64 instantiations across nesting).
- analogue module (SG-13, schema emath.analogue, version 1): budgeted numeric finite analogues of the SG-10 binder kinds. AnalogueRequest (kind, AnalogueDomain, BinderBudget, bound VariableId, BinderTerm body) evaluates the body as a strict-f64 function of the bound variable. Kinds: Sum/Product (left fold over an inclusive integer range), Integral (composite trapezoid on [a,b] with n subintervals), Derivative (central difference with explicit h), Limit (monotone right-hand dyadic samples). Custom kinds and nested binder bodies refuse. analogue_id is FNV-1a64 over the versioned canonical request; the budget is excluded from identity (same invariant as SG-10). Receipts serialize as BTreeMap-ordered JSON (`AnalogueReceipt::to_json`), values as IEEE-754 `to_bits()` hex. Production path: `cargo xtask demo finite-analogues`.
- synth module (SG-14, schema emath.finite-world, version 1): budgeted search for a binary operation table on a finite carrier `{0, …, n−1}`. SynthRequest (carrier_size, laws, examples, SynthBudget, resume_cursor) enumerates `n^(n²)` tables in a fixed row-major mixed-radix order and returns the first table that satisfies every law and example, or a typed refusal. Laws: commutative, associative, left/right/two-sided identity (named element or existential). Examples are `op(a,b)=c` triples. synth_id is FNV-1a64 over the versioned canonical request; budget and resume_cursor are excluded from identity (the identity is the constraint problem, not the execution parameters). Receipts serialize as BTreeMap-ordered JSON (`SynthReceipt::to_json`) and carry `tables_examined` plus `resume_cursor` (next unexamined index) so a caller can continue across budget windows. Production path: `cargo xtask demo finite-worlds`.
- meaning_provider module (SG-15, schema emath.agent-meaning, version 1): agent proposal admission and a producer-distinct challenge loop. AgentProposal (version, producer_id, OpTable, Vec<SynthLaw>, free-text rationale). `admit` performs well-formedness only (carrier bounds, cell ranges, version) and yields a QuarantinedCandidate with status `Quarantined` and authority `none`; it never evaluates or certifies claimed laws. `challenge(candidate, MeaningChecker)` refuses when `checker.id == producer_id` (`SelfCertification`, the named negative control) or when the checker lacks `law-check/v1` (`MissingCapability`). Otherwise it runs `check_table`: a violation demotes to `Rejected { violation }`; success promotes to `Checked { checker_id }` with authority `structural-checked` (never higher). proposal_id is FNV-1a64 over the versioned canonical encoding (producer + table + laws; rationale excluded). Receipts serialize as BTreeMap-ordered JSON (`MeaningReceipt::to_json`) with proposal_id, producer, checker, verdict (`quarantined`/`checked`/`rejected`/`refused`), counterexample when present, authority, and; on `refused`; the refusal reason token (`self-certification` or `missing-capability`; a refused receipt always says why). Production path: `cargo xtask demo agent-meaning`.
- morphism module (SG-16, schema emath.world-morphism, version 1): translate, compare, and deduplicate finite `OpTable` worlds; mine properties shared across portfolios. WorldMorphism is a total map of source carrier indices to target indices. `verify` checks the homomorphism law `map[op_s(a,b)] == op_t(map[a], map[b])` on every pair and returns the lexicographically first counterexample. `find_isomorphism` searches bijections in lexicographic order (first winner; sizes above `MAX_ISO_SEARCH_SIZE` = 5 refuse with BudgetExceeded; `MAX_ISO_CANDIDATES` is a hard cap). `quotient` partitions by observational equivalence (`x ≡ y` iff for all `z`, `op(x,z)==op(y,z)` and `op(z,x)==op(z,y)`), takes least-element representatives, and builds the class table (always well-defined under that definition; still verified). `mine_invariants` reports the synth law vocabulary (commutative, associative, existential left/right/two-sided identity) with per-world verdicts and the shared subset. `dedupe` groups by isomorphism, keeps the cells-lexicographic representative, and lists dropped members with a witness morphism. morphism_id is FNV-1a64 over the versioned canonical morphism (candidate budgets excluded). Receipts serialize as BTreeMap-ordered JSON. Production path: `cargo xtask demo world-morphisms`.
- tuning module (SG-18, schema emath.joint-tuning, version 1): budgeted joint search over semantic tables and host evaluation strategies under a protected real-program objective. TuningRequest (version, carrier_size, ProtectedObjective, TuningBudget, joint_cursor, incumbent) enumerates the semantic-major cross product of `OpTable::from_index` (same mixed-radix order as synth) and ImplVariant (`fold-left`, `fold-right`, `pairwise-tree`) and returns the lowest-cost qualified candidate, or a typed refusal. A ProtectedObjective is a set of host examples `chain(inputs) == expected` evaluated under the candidate's table and impl variant. Protection is absolute: failing any example is Disqualified and can never be selected; protection is not a weighted penalty. Secondary cost is op applications on the protected inputs plus table complexity (distinct cell values); ties break by lowest joint index. `semantic_dna` encodes meaning only (carrier size + cells) and is stable across impl variants; `candidate_id` is FNV-1a64 over versioned DNA + impl token. `tuning_id` is FNV-1a64 over the versioned canonical request; budget and joint_cursor are excluded. Receipts serialize as BTreeMap-ordered JSON (`TuningReceipt::to_json`) with winner dna/impl/cost, examined/qualified/disqualified counts, resume_cursor, and a disqualification ledger (candidate id + first failed example index). Production path: `cargo xtask demo joint-tuning`.

## Invariants

- Evaluating a well-formed term under a matching symbolic world never panics; all failure is typed via EvalError.
- Seed worlds bind exactly the reference alien signature; unknown symbols and wrong arities are errors, not fallthroughs.
- free_symbolic_world emits a provider-neutral free WorldIr with derived structural constructor semantics.
- Terms are built from emath_term structures in stable iteration order.

## Error model

- EvalError: MissingVariable, UnknownSymbol, Arity; converted into W::Error via From<EvalError>.
- Genesis syntax codes (E-SYN-201..211) are emitted by emath-syntax, not by this crate.
- AnalogueError: UnknownVersion, BudgetExceeded { limit }, InvalidDomain { reason } (`a>b`, `n=0`, `h<=0`, `non-finite-bounds`, `kind-domain-mismatch`, `approach-underflow`; the dyadic increment rounded to zero or was absorbed, so the next sample would land on the limit point itself), UnsupportedKind, EvaluationFailed { reason } (`unbound-variable`, `non-numeric-constant`, `unknown-operator`, `bad-arity`, `non-finite-value`). Empty integer ranges and inverted intervals refuse; no monoid identity is invented.
- SynthError: UnknownVersion { version }, BudgetExceeded { limit } (window filled with tables still unexamined; never a silent truncation), Unsatisfiable { tables_examined } (space exhausted inside the window; the impossible-law refusal), InvalidRequest { reason } (`empty-carrier`, `carrier-too-large`, `example-out-of-range`, `identity-out-of-range`, `cursor-out-of-range`). Independent law check `check_table` returns LawViolation { law, counterexample: [a,b,c] } rather than inventing a table.
- ProviderError (admission): UnknownVersion { version }, InvalidProposal { reason } (`empty-producer`, `empty-carrier`, `carrier-too-large`, `cell-count-mismatch`, `cell-out-of-range`, `identity-out-of-range`). ChallengeRefusal (protocol, challenge did not run): SelfCertification { producer } (checker id equals producer id), MissingCapability { required } (checker lacks `law-check/v1`). A law-check failure is not an error: it demotes the candidate to Rejected with the concrete LawViolation.
- MorphismError: UnknownVersion { version }, InvalidMorphism { reason } (`empty-carrier`, `carrier-too-large`, `map-length`, `image-out-of-range`, `table-length`, `cell-out-of-range`, `quotient-not-well-defined`, `iso-witness-missing`), SizeMismatch (declared morphism sizes do not match the supplied tables), BudgetExceeded { limit } (`MAX_ISO_SEARCH_SIZE` or `MAX_ISO_CANDIDATES`), NotAHomomorphism { pair } (lexicographically first failing source pair). A homomorphism-law failure is a typed counterexample, never a silent pass.
- TuningError: UnknownVersion { version }, InvalidRequest { reason } (`empty-carrier`, `carrier-too-large`, `no-protected-objective`, `empty-input`, `example-out-of-range`, `cursor-out-of-range`), BudgetExceeded { limit } (window filled with candidates still unexamined; never a truncated winner), NoQualifiedCandidate { examined } (space exhausted inside the window; none satisfied the protected objective). Disqualification is a classification, not an error: a candidate that fails a protected example is recorded in the receipt ledger and can never be selected.

## Determinism class

- Deterministic: WorldIr construction iterates a BTreeMap signature in sorted key order.
- Outputs are byte-comparable where serialized.
- VM traces are bit-identical across runs for the same term/world/valuation; VM results agree with the recursive evaluator (tested).
- CSA values are bit-exact across runs, hosts and tool versions (pure integer mixing, no floats).
- SpecializationCache is deterministic: identical insert/get/challenge sequences yield identical counters and BTreeMap key order.
- Finite analogues are strict-f64: one fixed IEEE-754 binary64 operation sequence per rule, values stored as `to_bits()`. Receipts are byte-identical across runs on IEEE hosts that implement the same operations. Not claimed across non-IEEE or flushed-subnormal environments. JSON key order is lexicographic via BTreeMap.
- Finite-world synthesis is pure integer enumeration: one fixed mixed-radix order (least-significant digit = row-major cell `(0,0)`), first winner by that order. Receipts are byte-identical across runs. JSON key order is lexicographic via BTreeMap. Split search at an arbitrary resume_cursor equals an unsplit search for the same constraints.
- Agent-meaning receipts are byte-identical across runs: proposal_id is FNV-1a64 over the versioned canonical proposal (producer + table + laws); rationale is excluded from identity. JSON key order is lexicographic via BTreeMap.
- World morphisms are pure integer table operations: homomorphism search is exhaustive over pairs; isomorphism search is lexicographic over bijections; quotient classes are ordered by least element; invariant law order is fixed; dedupe representatives are cells-lexicographic. Receipts are byte-identical across runs. JSON key order is lexicographic via BTreeMap. Candidate budgets are excluded from morphism_id.
- Joint tuning is pure integer enumeration: one fixed semantic-major joint order (table index outer, impl variant inner), winner is the lowest-cost qualified candidate with ties broken by lowest joint index. Receipts are byte-identical across runs. JSON key order is lexicographic via BTreeMap. Because the winner is a global cost minimum (not a first winner), `BudgetExceeded { limit, incumbent }` carries the best qualified joint index found so far, and the next window seeds `TuningRequest::incumbent` with it; the incumbent is re-verified (must precede the window and classify as qualified; `incumbent-out-of-window` / `incumbent-not-qualified` refusals), never trusted. Split search with the incumbent threaded equals an unsplit search for the same protected objective. Budget, cursor, and incumbent are excluded from tuning_id.

## No-claim boundaries

- Example worlds cover only the reference alien signature, not arbitrary user worlds.
- Provider-neutral by construction: no provider spawning or external evaluation occurs here.
- SpecializationCache does not compile, load, or execute specialized code; it only records and challenges WorldId-bound artifacts. WORLD_IR_VERSION / WORLD_ABI_VERSION bumps change identity or ABI, so an old cache entry cannot satisfy a challenge against a new WorldId (rollback is refuse-and-recompile; there is no on-disk cache to migrate).
- Binders make no convergence or continuum claims: FiniteAnalogue expansion is the declared analogue only, OpaqueSeeded identities are identities (not values), and Conventional binders are never evaluated. There is no persisted binder store; BINDER_VERSION consumers refuse unknown versions (check_version), so rollback/migration is refuse-and-rebuild; an old artifact citing a different version is rejected, never reinterpreted.
- Finite analogues never upgrade a numeric stand-in into a continuum theorem. Composite trapezoid documents the textbook `O((b-a)h²)` remainder and does not compute or certify it; central difference documents the textbook `O(h²)` truncation and does not compute or certify it. Limit sampling is the load-bearing honesty boundary: the receipt verdict is always `no-claim` (`ANALOGUE_NO_CLAIM`). Samples are evidence of the sampled monotone sequence; the verdict never claims the limit exists, that the sequence converges, or that the last sample is the limit. There is no persisted analogue store; ANALOGUE_VERSION consumers refuse unknown versions (`analogue::check_version`), so rollback/migration is refuse-and-rebuild; an old artifact citing a different version is rejected, never reinterpreted.
- Finite-world synthesis finds a finite table, not a continuum algebra or an infinite model. A winner is the first table in enumeration order that satisfies the stated laws and examples; it is not unique and is not claimed to be the intended meaning. There is no persisted synthesis store; SYNTH_VERSION consumers refuse unknown versions (`synth::check_version`), so rollback/migration is refuse-and-rebuild; an old artifact citing a different version is rejected, never reinterpreted.
- Agent meaning proposals are quarantined candidates, not certified worlds. Quarantine carries authority `none`. A successful challenge is `structural-checked` (EvidenceKind::Structural with a producer-distinct checker) and is never upgraded to a higher evidence kind. Self-certification is impossible by construction: `checker.id == producer_id` is a typed SelfCertification refusal, not a silent pass. The rationale field is free text and is never checked or bound into identity. There is no persisted proposal store; PROVIDER_VERSION consumers refuse unknown versions (`meaning_provider::check_version`), so rollback/migration is refuse-and-rebuild; an old artifact citing a different version is rejected, never reinterpreted.
- World morphisms, observational quotients, and mined invariants are claims about finite operation tables only, never about continuum structures, infinite models, or intended meaning. A homomorphism witness is a total map on carrier indices; a shared invariant is a synth-law that holds on every table in the supplied portfolio. There is no persisted morphism store; MORPHISM_VERSION consumers refuse unknown versions (`morphism::check_version`), so rollback/migration is refuse-and-rebuild; an old artifact citing a different version is rejected, never reinterpreted.
- Joint tuning selects among finite candidates under a protected host objective; it never claims the winner is the intended meaning. Disqualification is absolute (never a weighted tradeoff against cost). A winner is the lowest-cost qualified candidate in joint order, not a unique semantics and not a continuum algebra. There is no persisted tuning store; TUNING_VERSION consumers refuse unknown versions (`tuning::check_version`), so rollback/migration is refuse-and-rebuild; an old artifact citing a different version is rejected, never reinterpreted.

# CONTRACT; emath-tuning

## Purpose and layer
- Layer: Tier 7, governance and operations (per implementation/CRATE_MAP.md).
- Semantic and joint tuning: semantic tuning varies World IR components (carriers, symbols, signature, operator meanings, constants, constructors, laws, effects/capabilities) while protecting declared laws and held-out examples; joint tuning varies the world and implementation together.
- Promotion requires semantic admission, evidence threshold, resource envelope, fallback availability, and a deterministic receipt.
- Depends on: emath-term, emath-world-ir.

## Public types and semantics
- `SemanticVariable` / `SemanticVariableKind` - one tunable semantic variable and which World IR component it varies. Eight kinds, `Ord` by declaration order: Carrier, Symbol, Signature, Operator, Constant, Constructor, Law, Effect. Canonical names (`carrier` through `effect`) round-trip through `from_canonical`.
- `SemanticChange` - one concrete world change proposed by a candidate, with provenance. `replace` builds an operational patch whose `description` encodes prior then next, separated by `PATCH_SEPARATOR` (`U+001F`).
- `encode_patch` / `PATCH_SEPARATOR` - reversible payload encoding used by `WorldDelta::apply` / `WorldDelta::revert`.
- `WorldDelta` - base world plus deterministically sorted semantic changes. `locality()` is the sorted unique World IR component names the change set touches; `receipt()` builds a `DeltaReceipt`. `apply(&self, base: &WorldIr) -> Result<WorldIr, DeltaError>` writes each change onto a clone of `base`; `revert(&self, applied: &WorldIr) -> Result<WorldIr, DeltaError>` is the inverse, so `revert(apply(base))` restores `base`'s canonical form and `WorldId`.
- `DeltaError` - typed apply/revert refusal (`BaseMismatch`, `MissingTarget`, `PriorMismatch`, `MalformedPatch`, `NotReversible`, `IdentityUnchanged`, `DidNotRestore`). A delta whose target is absent from the world is `MissingTarget`, never a silent no-op.
- `DeltaReceipt` - binds a base world fingerprint (`u64`), the sorted applied-change canonical strings, and a deterministic receipt identity (FNV-1a64 over `canonical()`). Same input always yields the same identity. `locality()` recovers touched components from those strings.
- `ExecutionDelta` - implementation delta: lowering, precision, provider, target, schedule.
- `JointCandidate` - world delta plus execution delta with deterministic identity (`held_out_verified`, `evidence_units`, `identity`).
- `CoverageSample` / `CalibratedConfidence` / `calibrate_confidence` - recalibrates meaning confidence from construction vs held-out coverage; unused table capacity is a complexity penalty; a memorizing candidate (`held_out` below `MIN_HELD_OUT_PERMILLE`) is refused.
- `HostCampaign` - runs a campaign over candidates and their measurements; `run` returns a `CampaignReceipt`.
- `ResourceEnvelope` / `HostMetric` / `HostObjectives` - protected resource envelope, one host measurement, and protected-metric objectives.
- `CandidateMeasurement` / `PromotionChecklist` / `CandidateDecision` / `CampaignReceipt` - per-candidate measurement, promotion gates, decision, and deterministic campaign receipt.
- `frontier` module - frontier engine (aggressive generation, strict admission): `FRONTIER_SCHEMA` (`emath.frontier`) / `FRONTIER_VERSION` (1), `RewriteRule` (an algebraic rewrite hypothesis over one operator), `generate_algebraic_candidates` (deterministic: sorted by canonical form, deduplicated, budget-capped; every emitted candidate is unverified with zero evidence), and `verify_held_out` (runs the held-out challenge; evidence is awarded only on a pass, and the returned candidate has a fresh deterministic identity either way). Provenance of generated changes is `algebraic-rewrite`.
- (not exhaustive)

## Invariants
- Promotion requires all five gates: semantic admission, evidence threshold, resource envelope, fallback availability, and a deterministic receipt.
- A world that merely memorizes construction examples must not promote as a general meaning; every candidate is tested against held-out references before selection.
- The resource envelope admits fail-closed on missing cost or latency measurements.
- Selection among promoted candidates is deterministic; ties break toward the lower identity.
- When no candidate promotes, the campaign rejects and selects the fallback, and the receipt records that.
- A `DeltaReceipt` identity is a function of the base fingerprint and the sorted applied-change canonical strings only; presentation-only labels are not part of the preimage.
- Locality of a change set is the sorted unique World IR component names of its kinds (`carriers`, `symbols`, `signature`, `operators`, `constants`, `constructors`, `laws`, `effects`), so dependents re-check only affected obligations.
- `WorldDelta::apply` requires `base.identity() == base_world`, addresses all eight `SemanticVariableKind`s against existing World IR components, and a non-empty change set must produce a new `WorldId`. `revert` restores that original identity. Constructor/law/effect list entries may use the target `SymbolId` as the prior string when `PATCH_SEPARATOR` is absent; other kinds need an encoded prior to revert.
- Apply walks changes in canonical sort order; revert walks the reverse of that order. No hashing or iteration order leaks into the result.
- Frontier pipeline order is fixed: generate (unverified) → verify held-out → benchmark verified candidates only → campaign. The generator alone can never produce a promotable candidate, and an incorrect candidate is rejected at semantic admission before any benchmark exists for it.

## Error model
- `WorldDelta::apply` / `WorldDelta::revert` return `Result<WorldIr, DeltaError>`. Missing targets, base-identity mismatch, prior/next mismatch, malformed payloads, non-reversible descriptions, no-op identity, and a revert that does not restore `base_world` are typed refusals.
- `HostCampaign::run` returns a `CampaignReceipt` (not a `Result`); rejection of candidates is expressed through decisions, not errors.
- No panics.

## Determinism class
- Deterministic: candidate identity is FNV-1a64 over canonical form, promoted selection has a fixed tie-break (lower identity), campaign receipts and `DeltaReceipt` identities are FNV-1a64 over their canonical preimages, `SemanticVariableKind` / locality names are fixed strings, and world-delta apply/revert is a pure function of the world snapshot plus the sorted change list.
